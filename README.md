# Nipkow disk simulator

Интерактивная симуляция механического телевизора Нипкова с тёмным интерфейсом.

## Использование

1. Нажмите **Пуск**: диск постепенно набирает обороты.
2. Нажмите **Синхронизировать**, чтобы совместить скорость и фазу с сигналом.
3. Изменяйте обороты: рассогласование искажает картинку.
4. Выберите тестовую картинку или загрузите своё изображение. Файл обрабатывается только в браузере и никуда не отправляется.

Модель использует 32 строки, 48 отсчётов в строке, 12,5 кадра/с и номинальные 750 об/мин. Ход времени можно замедлить. В увеличенном окне строки геометрически выпрямлены для наглядности.

Сигнал яркости синтезируется из выбранного изображения; реальный WAV/NBTV-файл не декодируется. Параметры учебной модели не являются готовыми требованиями к аппаратной реализации.

## Файлы

- `index.html` — самостоятельная страница без внешних зависимостей и сервера приложения.
- `src/nipkow-simulator.html` — редактируемый исходный фрагмент симуляции.
- `.nojekyll` — публикация статических файлов через GitHub Pages.

Можно открыть `index.html` непосредственно в браузере или запустить локальный статический сервер. GitHub Pages публикуется из корня ветки `main`.
